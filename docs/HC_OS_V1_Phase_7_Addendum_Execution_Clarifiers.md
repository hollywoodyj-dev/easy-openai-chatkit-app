# Addendum — Phase 7 Execution Clarifiers

## Subject
Phase 7 Addendum — Habit Validation Guardrails

## Audience
Tree / Nova / Lumen / Wisewave

## Status
Active

## Purpose

This addendum formalizes the execution clarifiers for Phase 7.

Phase 7 is not only about observing reuse.
It is about correctly interpreting reuse, protecting trust, and avoiding false conclusions about habit formation.

The main risk in this phase is not lack of data.

The main risk is:

**misreading exposure, activity, or repetition as real habit formation.**

---

## 1. Repeat-use must be interpreted within comparable return conditions

Repeat-use is the main Phase 7 signal, but it must be read carefully.

The correct question is not:

**did the user use Continue again later?**

The correct question is:

**after one successful Continue use, does later reuse rise under similar high-value return conditions?**

### Why this matters

Aggregate reuse is noisy.

It can be distorted by:
- overall activity level
- conversation frequency
- random exposure differences
- unrelated return types
- temporary novelty effects

A stronger signal is:
- successful use in a specific high-value condition
- later reuse in a comparable condition
- continued successful resumed-turn quality in that same class

### Required implication

Nova and Lumen should segment reuse by return family, including where possible:
- unfinished emotional residue
- delayed-reply / replay-for-mistakes (`delayed_reply_replay`)
- worth-pressure / earned-rest tension
- interrupted articulation
- recent still-live unfinished return
- low-verbal resumable return (`low_verbal_resumable_return`)

### Interpretation rule

Reuse should count as strongest evidence of habit formation when:
- the later return condition is comparable
- Continue is selectively surfaced
- the user chooses it again
- the resumed-turn path remains coherent

Do not treat broad later reuse alone as proof of habit.

---

## 2. Zero-surfacing in weak cases remains a success condition

Phase 7 must not weaken the Phase 6 discipline.

In weak, shallow, low-confidence, or low-distinctness cases:

**zero-surfacing is a successful outcome, not a missed opportunity.**

### Why this matters

At this stage, there is a temptation to broaden appearance in order to generate more reuse data.

That would be a mistake.

Weak exposure can:
- spend trust budget
- create decorative feature feel
- train users to ignore Continue
- inflate apparent opportunity while weakening actual value

### Required implication

Nova should preserve strong suppression in cases such as:
- greetings
- thanks / acknowledgment-only replies
- logistical or scheduling tails
- shallow practical follow-ups
- obvious fresh-start openings
- low-distinctness candidate clusters

Lumen should explicitly treat successful non-appearance in these cases as a positive result.

### Hard rule

Do not increase weak-case exposure in order to:
- gather more usage data
- create more impressions
- raise CTR
- “test more broadly”

That would contaminate the habit signal.

---

## 3. A habit signal is invalid if it depends on visibility inflation

A critical Phase 7 guardrail:

**If reuse rises because Continue is shown more often, that is not enough to count as habit formation.**

### Why this matters

Habit formation should mean:
- users trust Continue when it appears in the right moments
- users choose it again because it helped before
- reuse grows through earned relevance

It should not mean:
- the feature became harder to ignore
- the feature appeared in more marginal cases
- the system generated more opportunities by lowering standards

### Required interpretation rule

Tree, Nova, and Lumen should treat reuse growth as credible only when it occurs alongside:
- stable or lower weak-case impression rate
- preserved strong-case quality
- preserved ignore-path cleanliness
- no rise in conceptual heaviness
- no increase in weak-candidate surfacing
- normalized same-pattern rates (not raw volume shifts)

If reuse grows while weak exposure also grows, the result is suspect.

---

## 4. The strongest proof point remains first resumed-turn quality

Even in Phase 7, the deepest trust signal is still not the list.

It is still:

**what happens in the first reply after selection.**

### Why this matters

A user may click Continue out of curiosity, convenience, or habit.

But the mechanism only earns repeated trust when the first resumed turn proves:
- the selected direction was actually picked up
- the user did not need to restart
- minimal re-entry language still works

### Required implication

Nova must continue protecting:
- short-ack continuation
- low-verbal re-entry quality
- selected-direction coherence
- non-generic resumed replies

Lumen should keep this as a top QA gate.

Wisewave should continue to evaluate whether the post-selection moment feels like:

**“we’re back there”**

rather than:

**“the system guessed again”**

### Interpretation rule

A reuse event with weak resumed-turn quality should not be treated as strong habit evidence.

---

## 5. Ignore-path cleanliness is part of habit quality

A healthy habit layer is not a compulsory step.

Therefore:

**clean ignore behavior remains part of success, even in Phase 7.**

### Why this matters

If Continue begins to feel:
- required
- interruptive
- over-present
- awkward to skip

then any rise in usage may reflect pressure, not trust.

### Required implication

Lumen should continue validating:
- ignore → clean new direction
- no friction after non-use
- no behavioral penalty for skipping Continue

Wisewave should watch for:
- subtle pressure feel
- over-presence
- feature gravity that pulls attention when it should stay light

### Interpretation rule

Reuse is higher quality when ignore remains equally clean.

---

## 6. Label quality still matters, but only as a support layer

Label quality remains relevant, but it is no longer the main bottleneck.

### Why this matters

At this stage, the larger risks are:
- bad exposure
- false reuse conclusions
- trust drift
- resumed-turn weakening

Label polish should support:
- recognizability
- distinctiveness
- quick intuitive choice

It should not become the main optimization track unless it clearly harms strong-case trust.

### Required implication

Nova should only revisit label-floor work if:
- thinness begins to damage strong-case recognition
- distinctiveness degrades
- label weakness begins to reduce trust quality materially

Do not let the team fall back into copy-loop optimization as a substitute for trust validation.

---

## 7. Watchpoint escalation rules

These conditions should trigger concern during Phase 7.

### Escalate if:
- reuse rises while weak-case exposure also rises
- resumed-turn coherence weakens in strong cases
- zero-surfacing drops because standards were loosened
- ignore begins to feel less clean
- strong families stop surfacing reliably
- labels become too thin to support recognition in high-value moments
- Continue starts feeling more present, more explanatory, or more object-like

### Do not escalate if:
- impressions fall while trust quality improves
- zero-surfacing remains common in weak cases
- usage remains selective but strong in high-value moments
- reuse grows slowly but credibly within comparable return conditions

Slow, selective dependence is acceptable.
Shallow broadening is not.

---

## 8. Final interpretation rule for Phase 7

Phase 7 should be judged by this standard:

**Continue is approaching habit-layer status only if repeated use grows through selective trust, preserved strong-case performance, and stable low-value suppression.**

Not through:
- greater visibility
- broader exposure
- more explanation
- weaker thresholds
- noisier opportunities
