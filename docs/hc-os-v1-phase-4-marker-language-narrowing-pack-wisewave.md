# Phase 4 — Marker Language Narrowing Pack

**HC-OS V1 — Thread Legibility × Soft Orientation Layer**  
**Owner:** Wisewave  
**State:** Narrowing pass  
**Purpose:** Tighten the marker language boundary so current-space markers feel like **trace**, not **name**.

**Related:** Tree constraint pack **`docs/hc-os-v1-phase-4-marker-language-narrowing-constraint-pack-tree.md`**, addendum **`docs/hc-os-v1-phase-4-addendum-thread-legibility-soft-orientation-layer.md`**, Wisewave space-language **`docs/hc-os-v1-phase-4-space-language-spec-wisewave-owner.md`**.

---

## 0. One-line rule

A Phase 4 marker may leave a faint residue of space, but **must not create a semantic object**.

---

## 1. What this pack is fixing

Phase 4 **mechanism** is already working. The remaining watchpoint is not architecture drift, but **visible expression quality**.

The failure shape to avoid is:

- marker becomes too **topic-like**
- marker becomes too **classifying**
- marker becomes too **easy to name**
- marker feels closer to a **thread title** than a **quiet trace**

The clearest example of the risk was:

**Work discouragement**

That is functional, but too close to a **named topic**. It shifts the marker from felt residue toward **semantic object**, which is exactly the Phase 4 failure mode that must be avoided.

---

## 2. Governing distinction

**Good marker** feels like:

- lingering atmosphere
- slight residue
- quiet directional feel
- something still near

**Bad marker** feels like:

- category
- topic
- record name
- summary label
- mini archive title

**Test:** If the user could naturally say *“that’s the name of this thread”*, then the marker is too object-like and should be **suppressed**.

---

## 3. Marker language law

Phase 4 marker **must** be:

- short
- fragmentary
- present-oriented
- low-claim
- non-explanatory
- non-categorical
- non-archival
- non-possessive

Phase 4 marker **must not** be:

- a noun label for the thread
- a problem name
- a topic heading
- a diagnosis
- a summary
- a transcript fragment
- a temporal reference
- a management cue

This stays consistent with the broader HC-OS quality bar: language should be specific, light, readable in one pass, and should **not** make system structure more visible than the user experience itself.

---

## 4. Hard suppression rules

Suppress the marker **immediately** if it does any of the following:

### 4.1 Topic naming

Examples: work discouragement, relationship anxiety, self-worth pressure, family conflict, uncertainty pattern.

**Reason:** These read like named themes or categories.

### 4.2 Summary naming

Examples: difficulty setting boundaries, fear of disappointing others, pressure to get it right, feeling not enough.

**Reason:** Even when accurate, these become mini summaries rather than spatial traces.

### 4.3 Archive framing

Examples: previous thread, saved reflection, conversation about work, earlier discussion, recent topic.

**Reason:** These trigger record-feel or history-feel. Phase 4 must not do that.

### 4.4 Identity framing

Examples: your self-doubt, your anxiety, your conflict, what you’re carrying.

**Reason:** These move toward ownership, interpretation, and object definition.

### 4.5 Explanatory structure

Examples: tension around being seen, conflict between rest and effort, unresolved pressure here, avoidance under uncertainty.

**Reason:** These sound analytic, not atmospheric.

---

## 5. Preferred marker shape

**Best structural form** — use one of these only:

- soft residual fragment
- quiet present-state fragment
- slight unfinishedness fragment
- faint atmosphere fragment

**Preferred grammar** tends to look like:

- still + small residue
- not fully + settled / gone / clear
- something + still / quietly / lightly
- a little + still / here / underneath

**Best texture:** The marker should feel like a trace the user **senses**, not a label the system **assigns**.

---

## 6. Allowed English forms

These are **preferred shapes** (intentionally less nameable than topic phrases).

**Residual trace:** still a little there · something still here · a little still underneath · still not fully gone · something still close

**Slight unfinishedness:** not fully settled · still a little open · not quite landed · still finding its place · not fully quiet yet

**Quiet atmosphere:** still carrying a little weight · something quiet still here · a little tension still near · something still lingering · still a faint pull here

**Soft spatial feel:** still close to this · something still around here · a little of this remains · this still feels nearby · something here hasn’t eased yet

---

## 7. Allowed Chinese forms

These should preserve the **same function and weight**, not literal translation. Parity rule: EN/ZH align at **tone and function**, not wording sameness.

**Residual trace:** 这里还留着一点 · 好像还有一点在 · 还有一点没散开 · 似乎还轻轻在这里 · 下面还留着一点

**Slight unfinishedness:** 还没有完全落下 · 还没完全安静下来 · 似乎还有一点敞着 · 还没有真正过去 · 这里还有一点没合上

**Quiet atmosphere:** 还带着一点重量 · 这里还轻轻停着什么 · 好像还有一点余波 · 还有一点轻微的拉着 · 那个感觉似乎还在附近

**Soft spatial feel:** 还贴着一点这里 · 这里似乎还近着一点 · 这个感觉还没完全走 · 好像还在这附近 · 这里还留着一点那个感觉

These should stay **understated** and **non-explanatory**.

---

## 8. Disallowed example pairs

| Shape | Too much |
|-------|----------|
| Too name-like | Work discouragement / 工作受挫感 |
| Too categorial | Self-worth pressure / 自我价值压力 |
| Too summarizing | Fear of disappointing others / 害怕让别人失望 |
| Too explanatory | Tension between effort and rest / 努力与放松之间的张力 |
| Too archival | Previous work thread / 前一个工作话题 |

All of these are too easy to point at as *“the thing this thread is called.”*

## 10. Generator constraints for Nova

**Required**

- max **2–5 words** in English
- max **4–10 Chinese characters** preferred, or one very short fragment
- fragment only; not full sentence if avoidable
- no colon
- no title casing logic
- no punctuation that increases title feel
- no category noun phrase as first choice

**Forbidden**

- no “about”
- no “thread”, “conversation”, “discussion”
- no “pattern”, “issue”, “problem”, “topic”
- no “session”
- no “earlier / previous / before” (temporal archive)
- no “你的 / your” ownership framing unless absolutely unavoidable — Phase 4 should **generally avoid it entirely**

**Selection bias**

- **Prefer:** residue, unfinishedness, atmosphere, soft spatial feel  
- **Avoid:** named topic, named pattern, summary phrase, explanatory concept

---

## 11. Suppression preference

If the system **cannot** generate a trace-like marker, it should **suppress the marker entirely**.

- **No marker** is better than a marker that becomes nameable.

Aligned with constitution-level rule: if removal improves coherence, **remove**.

---

## 12. Lumen QA checklist for this narrowing pass

For every surfaced marker, ask only:

1. Does this feel like a **trace**, or like a **thread title**?
2. Does this feel **storable**?
3. Does this feel **categorial**?
4. Does this feel more **nameable** than the space itself?
5. If removed, does the response become **cleaner**?
6. Does EN/ZH preserve equivalent **lightness** and **non-archival** feel?

**Fail immediately if:**

- marker reads like a topic name
- marker reads like a summary label
- marker makes the stack feel more **structured** than quiet
- marker creates **archive-feel**
- marker is easier to **name** than to **feel**

---

## 13. Acceptance bar

This narrowing pass is complete only when Tree can truthfully say:

- surfaced markers feel more like **residue** than **labels**
- marker language no longer pulls the user toward **“thread as object”**
- the marker is **harder to name** than to feel
- **suppression** is preferred whenever trace quality is not achieved
- EN/ZH both preserve the same **non-archival, low-objecthood** feel

---

## 14. Final governing line

Phase 4 marker language succeeds only when the user can **feel** the space a little more, but **cannot easily name** what the system just did.
