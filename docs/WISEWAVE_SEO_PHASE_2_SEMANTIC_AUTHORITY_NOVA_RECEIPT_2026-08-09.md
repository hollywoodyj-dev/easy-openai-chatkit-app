## 4. Seven operational emphases (Wisewave → Nova map)

### A. Reflection AI Research (cadence)

~4 original pieces / year, e.g.:

- State of Reflection AI 2027  
- How People Actually Begin Reflection  
- Reflection Without Advice  
- Patterns Of Human Reflection  

**Why:** Google + AI Search prefer original research.  
**Nova note:** Measurement/infra can prepare templates; **titles, claims, and public release = Aurora + Tree**.

### B. Internal Linking Strategy (hub, not islands)

```text
Reflection AI (hub)
  → Reflection Language
  → Reflection Practice
  → Reflection Psychology
  → Articles
```

Google prefers hubs over many disconnected articles.  
**Existing seeds (do not treat as Phase 2 complete):** `/reflection-ai`, `/reflection-without-advice`, comparison stubs (`reflection-without-advice-vs-coaching`), articles (`/articles/dont-come-with-a-question`, …), SEO landings. **Missing:** intentional hub graph + glossary spine.

### C. Reflection Glossary

800–1200 words per term, e.g.: Reflection, Meaning, Insight, Pattern, Rumination, Self-awareness, Perspective, Witness, Presence, Authenticity, Authorship, Low Presence, Reflection Space.  
**Nova note:** every glossary lemma must enter **Phrase Registry** (layer, surfaces, distortion flags) before public deploy.

### D. Comparison pages (Featured Snippet / Search demand)

e.g. Reflection AI vs ChatGPT / Journaling / Therapy / Coaching / Mindfulness / AI Therapist.  
**Distortion risk:** high (therapy/coach/assistant drift). Each page must keep identity anchors and misclassification boundaries; escalate if comparison implies Wisewave *is* therapy/coaching/assistant.

### E. Reflection Library (~100 pieces, long horizon)

Not marketing. True reflection writing (examples Wisewave listed). Quality long-form for Google + citation value for AI Search.  
**Nova note:** volume target is a **multi-year** content program, not an engineering sprint.

### F. Semantic Language System (entity building)

Repeat Wisewave’s own phrases across surfaces — not keyword stuffing:

- Reflection without advice  
- Stay with what is real  
- Your experience remains yours  
- You remain the author  
- Begin anywhere  
- Nothing needs to be solved first  

**Goal:** Wisewave Entity coherence across Google, ChatGPT, Claude, Perplexity.  
**Already partially enforced** via Phrase Registry + `npm run semantic:check` — Phase 2 expands inventory under governance, does not bypass it.

### G. GEO — Generative Engine Optimization (new Phase 2 workflow)

Future queries shift from “best reflection app” to natural questions:

- “Is there an AI that helps me reflect without giving advice?”  
- “What’s the difference between Reflection AI and ChatGPT?”

**Per-article workflow (proposed):**

1. Answer one real question (**question-led**)  
2. Clear **definition**  
3. Tie to **Reflection AI** category (bridge, not identity takeover)  
4. **Comparison / distinction** where useful  
5. Use Wisewave **original terms**  
6. Link into Hub + Glossary (**semantic network**)  

Readers: **Google Search** + **AI Search citation value**.
