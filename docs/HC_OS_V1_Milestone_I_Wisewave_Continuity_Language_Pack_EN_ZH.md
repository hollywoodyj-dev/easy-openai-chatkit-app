# HC-OS V1 — Milestone I (Wisewave) Continuity Language Pack (EN + ZH)

Owner: Wisewave
State: READY FOR NOVA IMPLEMENTATION

## 1. Core Purpose（核心目的）

让连续性被“感觉到”，而不是被“表达出来”。

Continuity should:

- be felt
- be subtle
- be unannounced

It must NOT:

- look like memory
- sound like recall
- behave like a feature

## 2. Core Language Principle（语言总原则）

Carry forward lightly, do not restate

好的连续性是：

- 氛围在延续
- 张力在延续
- 内在空间在延续

而不是：

- 内容被重复
- insight 被重说
- 系统在“记住你”

## 3. Tone Rule（语调规则）

Continuity must feel:

- calm
- light
- unannounced
- coherent
- non-explanatory

禁止：

- 分析感（analytical）
- 解释感（explanatory）
- 记忆感（recall-like）
- 权威感（authoritative）

## 5. Forbidden Language（绝对禁止）

以下表达 一律禁止（Nova需过滤）：

❌ Explicit Recall（显性回忆）

- as before
- like before
- earlier you said
- this came up before
- 像之前一样
- 你前面说过
- 这之前出现过

❌ Pattern Replay（模式重播）

- self-worth pressure
- over-efforting
- recurring pattern
- 自我价值压力
- 过度用力
- 重复模式

❌ Authority Tone（权威解释）

- this shows
- the underlying issue is
- what is happening is
- 这说明
- 底层问题是
- 这里发生的是

## 6. Show / Hide Rules（显示规则）

✅ Show only when：

- 同一内在空间明显仍在
- 不需要显性回忆
- 不会增加系统存在感

❌ Must hide when：

- thread 弱
- 需要解释才能成立
- 已有 E 或 H
- main reflection 已足够

🔒 Absolute rule:

If it feels like memory → suppress

## 7. EN / ZH Parity Rule（中英文一致性）

不是逐字翻译，而是：

- 相同“轻度”
- 相同“非权威感”
- 相同“不可见机制”

## 8. Acceptance Bar（验收标准）

Tree 可以用这 4 条判断是否通过：

- 连续性是“感觉到”的，而不是“被说出来的”
- 完全没有 recall 感
- 不与 main reflection 竞争
- 看起来像“同一个内在空间”，而不是系统记忆
