## What this means (precise)

### Achieved — core proof

| | |
|--|--|
| **Controlled exception** | H behaves as a **controlled exception**, not an **ambient** layer |
| **Optional / suppressible / non-dominant** | H is optional, suppressible, and does not dominate the product |
| **Yields to E** | H correctly yields to Milestone **E** (recurrence) |
| **Kill switch** | Works |
| **EN / ZH parity** | Parity bug found and fixed (behavior layer) |
| **Founder demo path** | Exists |

**Interpretation:** The **concept** of H is **validated**.

### Not yet “clean” — watchpoints (not failures)

1. **Whole-turn heaviness (residual)**  
   Reflection layer still sometimes: too resolved, slightly guiding, slightly authorial.  
   **Root** of Pass 4 revision.

2. **Selector / taxonomy bluntness**  
   Suppression reasons sometimes too generic (`vague_source`); cue-type differentiation not sharp enough — system still **coarse-grained** in some cases.

3. **Layer stacking**  
   **E + F** already creates visible structure. **H** must stay **strictly suppressed** in those cases — **sensitive balance**.

4. **Light Mode dependency**  
   H works cleanly partly because **Reflection Style v2 / Light Mode** is active.  
   **If Light Mode drifts → H breaks again.**

## Stabilization checklist (Tree-ready)

Tree should treat stabilization as **in progress** until:

| # | Gate | Criterion |
|---|------|-----------|
| 1 | **Suppression dominant** | Most turns → **no H**. No drift toward “always-on.” |
